# Workout history

`history.json` lands here when you press **Push** in the app's Settings tab.
It is the full training log — every session, every set — and it is the file to
point Claude at when you want coaching input.

The file is written by the GitHub Contents API from the phone, so the commits
show up like any other change. Nothing here contains credentials: the sync
token stays in the browser and is stripped from the export.
